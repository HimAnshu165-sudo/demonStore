# INFINITY CASTLE // 無限城 — Cinematic Streetwear Universe

An interactive 3D WebGL streetwear e-commerce experience inspired by the impossible Japanese gothic architecture of the Infinity Castle.

## Features

- **Cinematic WebGL Journey**: 6 connected environmental scene plates with Catmull-Rom camera splines, 3D parallax layering, and procedural GLSL fog transitions.
- **Editorial Typography**: 3-depth asymmetric parallax typography with high-fashion Japanese editorial art direction.
- **Climactic Climax Sequence**: 10-second Zenitsu Agatsuma Final Form sequence with Web Audio thunder synthesis and seamless e-commerce handoff.
- **Collection Catalog (`/shop`)**: Asymmetric luxury fashion catalog with minimal text filters, dual-angle hover transitions, and technical garment metadata (420–600 GSM).
- **Product Detail (`/product/[slug]`)**: Digital fashion editorial showcase with multi-angle gallery, luxury size selector, and expandable construction specifications.
- **Lookbook (`/lookbook`)**: Full-bleed campaign compositions (LOOK 01 to LOOK 05).
- **The World / Manifesto (`/world`)**: Brand philosophy and heavyweight textile craft.
- **Archive Search & Bag**: Full-screen live search overlay with keyboard ESC dismissal, slide-in bag drawer, and minimal publication-style checkout (`/checkout`).

## Tech Stack

- **Framework**: Next.js 15 (App Router, SSG static pre-rendering)
- **3D & Visuals**: Three.js, React Three Fiber (`@react-three/fiber`), GLSL Simplex/FBM Noise Shaders
- **Styling**: Vanilla CSS Modules with Google Fonts (`Cinzel`, `Space Grotesk`, `Noto Serif JP`)
- **Audio Engine**: Procedural Web Audio API soundscape & thunder synthesizer

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
